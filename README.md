## 📸 FITUR BARU: Ganti Foto Langsung dari File / Galeri HP
Sekarang Anda bisa **langsung mengganti foto hanya dengan mengklik fotonya**:
1. **Ganti Foto Evina**: Klik lingkaran foto Evina di bagian atas (Hero) atau di kartu profilnya -> Jendela pemilihan berkas / galeri HP akan langsung terbuka -> Pilih foto Anda -> Foto langsung terpasang otomatis!
2. **Ganti Foto Ilmy**: Klik lingkaran foto Ilmy -> Pilih foto dari file komputer / HP -> Foto langsung terpasang!
3. **Ganti Foto Galeri Momen**: Pada bagian *Galeri Momen Bersama*, klik tombol **"Ganti"** pada foto yang ingin diubah -> Pilih foto momen kalian berdua!
4. **Tersimpan Otomatis (*Auto-Save*)**: Foto yang Anda pilih disimpan secara lokal di browser (`LocalStorage`), jadi saat halaman di-refresh (*reload*) atau dibuka kembali, foto Anda tidak akan hilang.
5. **Tombol Reset Foto**: Terdapat tombol **"Reset Foto"** di bagian galeri jika ingin mengembalikan ke foto contoh awal.
